Utilisation
===========

OC Lettings Site est une application web permettant de consulter des annonces de location ainsi que des profils utilisateurs.

L'application est accessible via un navigateur web.

Navigation générale
-------------------

Depuis la page d'accueil (``/``), l'utilisateur peut accéder aux différentes sections du site :

- la liste des annonces de location
- la liste des profils utilisateurs

Consultation des annonces de location
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

L'utilisateur peut accéder à la liste des annonces via la page ``/lettings/``.

Depuis cette page, il est possible de consulter le détail d'une annonce en cliquant sur celle-ci.

Chaque annonce affiche :

- un titre
- une adresse complète associée au logement
- le pays

Consultation des profils utilisateurs
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

La liste des profils est accessible via la page ``/profiles/``.

Depuis cette page, l'utilisateur peut consulter le détail d'un profil en cliquant sur un utilisateur.

Chaque profil affiche :

- le prénom de l'utilisateur
- son nom
- son email
- sa ville favorite (si renseignée)

Administration
--------------

Une interface d'administration est disponible à l'adresse ``/admin/``.

Elle est réservée aux utilisateurs disposant des droits d'administration et permet de gérer les annonces, adresses et profils.
